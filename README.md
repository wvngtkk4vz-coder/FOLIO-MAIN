# Folio

A browser-based "famous author" life simulator with an Instagram-style interface. You are the author. The simulation runs thousands of procedurally generated fans, critics, haters, rival authors, journalists, publishers and celebrities who react to what you post, remember what you say, and build theories about your world.

Everything runs locally in the browser. There are no servers, no accounts and no AI calls. All text is generated by rule-based templates.

## Run it

Open `index.html` in any modern browser, or host the repo with GitHub Pages (Settings → Pages → deploy from the main branch, root folder).

## Features

- Character and book creation wizard, with lore that is auto-expanded
- Home feed, profile, explore and search, trending, notifications, stories, highlights
- All post types: teaser, cryptic, lore reveal, cover reveal, release, poll, Q&A and more, with image upload
- Threaded comments: reply, pin, delete, and confirm, deny or keep secret to set canon
- Direct messages in both directions with fans, critics, authors, press, publishers and celebrities
- Rumours, fan theories, fan wars, leaks, viral posts and rare events
- Fans remember your past interactions, and a repetition filter keeps comments varied
- Sim clock with slow, normal, fast, very fast and paused speeds, plus time skip
- Reputation stats such as fame, loyalty, trust, mystery, hype and controversy
- Responsive for phone, tablet and desktop, with light and dark themes
- The world autosaves to the browser's localStorage

## Develop

Source lives in `src/` and is concatenated into one file:

```
./build.sh
```

## Notes

- Fonts load from Google Fonts and fall back to system fonts when offline.
- Saves live in your browser. Clearing site data erases the world.
